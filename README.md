# Matrix Machine Lab

A beginner-friendly, interactive presentation for the QMB 6875 linear-algebra mini-lectures (Version 4, the "no-panic" edition).

**The one idea:** a matrix is a machine that moves arrows.

- **Person 1:** vectors as shopping lists, the matrix machine (with a determinant "squash meter"), matrix multiplication as a grocery bill, an eigenvector hunt, turn-stretch-turn (spectral decomposition), the Cholesky "smoothie trick", and the inverse as an undo button.
- **Person 2:** a lemonade stand selling two drinks. Find the top of the profit hill yourself, then see the math answer.
- **Person 3:** bowls, hills, Pringles and half-pipes; a knob that turns a circle into X-curves; and a shape quiz with a score.

**Controls:** ← → to move between slides, `N` for speaker notes, `F` for full screen. The color dots in the top bar switch palettes.

The whole thing is one file, `index.html`, with no build step. Open it in any browser, or host it with GitHub Pages.
